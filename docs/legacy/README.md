# legacy — 前两个版本的只读快照

> 本仓库（根目录）是 **v3 最终形态**。此目录保留 v1 / v2 的源码快照，
> 用于展示三版本演进叙事：**能造系统（v1）→ 能重构系统（v2）→ 能交付系统（v3）**。
> 快照仅作阅读参考，不在本仓库构建。

| 目录 | 版本 | 形态 | 被下一代取代的原因 |
|------|------|------|--------------------|
| `v1-cpp/` | C++17 原创版 | gRPC 四模式 + libcurl + nlohmann/json；MCP 集成 + RAG-MCP 工具选择；内存注册中心 | "假流式"（算完再切片 sleep 模拟）、跨平台构建痛苦、无指标体系、动态库插件不安全 |
| `v2-go/` | Go 生产级重写 | 三支柱架构确立：混合检索+token 背包路由 / 真·流式编排 / WASM 沙箱（wazero）；Prometheus+OTel | 功能完整但离生产缺三样：审批闭环（HITL）、调用方治理（govern）、2025→2026 协议合规 |
| （仓库根） | **v3 当前版** | v2 三支柱 + 任务持久化/HITL + 治理横层 + A2A v1.0 签名 + MCP 三版本协商 + anti-rug-pull + **v3.1 评测子系统** | — |

各版本自身的 README / docs 随快照保留：

- `v1-cpp/README.md` —— C++ 版完整设计文档（1132 行，含架构/部署/MCP 插件开发指南）
- `v2-go/README.md` + `v2-go/docs/` —— Go 重写版说明与架构文档

v3 相对快照的增量见根目录 `README.md` 与 `docs/ARCHITECTURE.md`；
量化指标见 `docs/BUILD.md §12`（`make eval` 可复现）。
